# Serenity Spa HTML/CSS/JavaScript
No React, no Vite, no Node required.

1. Supabase: ejecuta `supabase/schema.sql`.
2. Authentication > Users: crea el administrador.
3. Storage: crea un bucket público llamado `spa-images`.
4. En `config.js` coloca URL y clave pública.
5. Abre `index.html` con VS Code + Live Server.

Para publicar: sube estos archivos a GitHub Pages, Netlify, Vercel o cualquier hosting estático.

Nunca uses `service_role` en `config.js`.
